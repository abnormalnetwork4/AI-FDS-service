### 백엔드

원본 통신 경로 밖에서 캡처 복사본을 사후 분석하는 Out-of-Path FDS 백엔드는 [`backend/`](backend/)에 있습니다.
실행 방법, API 목록, 모델 연결 위치는 [백엔드 README](backend/README.md)를 참고하세요.
사용자와 AI의 원본 통신은 그대로 유지합니다. FDS는 별도 수집기가 전달한 통신 메타데이터·사용 로그를 저장하고 분석하며, 결과 조회 API를 제공합니다. 요청 전달·허용·차단 기능은 없습니다. 실제 캡처 수집기, 탐지 모델, 대시보드 화면은 후속 연결 대상입니다.
