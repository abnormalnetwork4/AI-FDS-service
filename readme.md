### 백엔드

사내 AI Gateway와 FDS 분석 서버를 분리한 FastAPI + SQLite 기반 구조는 [`backend/`](backend/)에 있습니다.
실행 방법, API 목록, 모델 연결 위치는 [백엔드 README](backend/README.md)를 참고하세요.
Gateway는 모델 허용 목록·입력 크기 정책에 따라 요청을 통제하고 사내 AI로 전달합니다. FDS는 별도 전달된 기록을 받아 최근 5분/1시간 행동을 집계하고 분석 결과를 제공합니다. 실제 탐지 모델과 통합 등급 정책은 연결 대기 상태입니다.
