### 백엔드

원본 통신 경로 밖에서 캡처 복사본을 사후 분석하는 Out-of-Path FDS 백엔드는 [`backend/`](backend/)에 있습니다.
실행 방법, API 목록, 모델 연결 위치는 [백엔드 README](backend/README.md)를 참고하세요.
사용자와 AI의 원본 통신은 그대로 유지합니다. FDS는 별도 수집기가 전달한 통신 메타데이터·사용 로그를 저장하고 분석하며, 결과 조회 API를 제공합니다. 요청 전달·허용·차단 기능은 없습니다. 실제 캡처 수집기와 탐지 모델은 후속 연결 대상입니다.

### 대시보드

이벤트 발생 시 `/api/v1/ingest/events`로 보내면 통신 종료를 기다리지 않고 분석을 시작합니다. 각 엔진 결과가 저장되면 SSE 변경 알림으로 화면을 갱신합니다. 5분·60분은 과거 행동 집계 범위이며 분석 실행 간격이 아닙니다. 입력 예시와 재전송 방법은 [백엔드 README](backend/README.md)를 참고하세요.

[`frontend/`](frontend/)의 React 화면이 백엔드 조회 API에 연결돼 있습니다. 캡처별 Network/Data 분석, 미판정·오류 상태, 저장된 근거 요약과 CSV 내보내기를 제공합니다.

백엔드(8000번)와 프론트엔드(5173번)를 각각 실행한 뒤 http://127.0.0.1:5173 에 접속합니다. Docker 없이 실행하는 명령과 샘플 데이터 전송 방법은 [프론트엔드 README](frontend/README.md)에 있습니다. 현재 모델과 통합 등급 정책은 미연결이므로 미판정은 안전 판정을 뜻하지 않습니다.
